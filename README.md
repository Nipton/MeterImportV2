# MeterImportV2
WPF-приложение для автоматизации импорта показаний общедомовых приборов учёта (ОДПУ) из Excel-файлов в подготовленные шаблоны.

## Описание проекта
До автоматизации данные по приборам учёта обрабатывались вручную: необходимо было открывать файлы с показаниями, высчитывать текущие показания, переносить значения в шаблоны и учитывать особенности разных организаций и типов ресурсов.
Приложение автоматизирует этот процесс:
- чтение показаний из Excel-файлов;
- обработка разных форматов данных для разных компаний;
- расчёт потребления;
- заполнение подготовленных шаблонов;
- проверка некорректных и конфликтующих данных;
- формирование журнала сообщений об импорте.
  
## Возможности
- Импорт показаний электроэнергии и холодной воды.
- Поддержка разных поставщиков и форматов Excel.
- Настройка расположения колонок через `settings.json`.
- Обработка тарифных зон.
- Обработка объединённых ячеек.
- Проверка дубликатов приборов учёта.
- Обнаружение конфликтующих записей:
  - один прибор с разными тарифными зонами;
  - одновременное наличие круглосуточного и зонных тарифов.
- Журнал обработки с разделением на информацию, предупреждения и ошибки
  
## Результат
- Автоматизирован процесс, который раньше выполнялся вручную
- Ручная обработка файла с показаниями занимала 15–20 минут, приложение выполняет тот же объём за несколько секунд
- Исключены ошибки ручного переноса данных
- Автоматическая валидация выявляет конфликты, которые раньше находили вручную
- Журнал обработки позволяет быстро понять, какие записи требуют внимания
- Настройка колонок через JSON позволяет адаптировать программу к изменениям без перекомпиляции
- Унифицирована обработка показаний для разных компаний

## Технологии
- .NET 9, C# 13
- WPF, MVVM
- ClosedXML
- Microsoft.Extensions.DependencyInjection
- Microsoft.Extensions.Configuration
- xUnit

## Ключевые паттерны
- **MVVM** — разделение UI и логики
- **Фабрика** — создание ридеров и врайтеров в зависимости от ресурса и компании
- **Шаблонный метод** — общая логика чтения в BaseReader
- **Стратегия** — взаимозаменяемые реализации IReadingsReader
- **Dependency Injection** — все зависимости внедряются через конструкторы, внедрение настроек с помощью IOptions

## Тестирование
Для проекта написаны интеграционные тесты. Все тесты работают с **реальными Excel-файлами** (`.xlsx`), которые хранятся в папке `TestData/`. Это позволяет проверять не только бизнес-логику, но и корректность парсинга данных, работу с объединёнными ячейками, пробелами и различными форматами ввода. Каждый тест работает с изолированными данными, не влияет на другие тесты, самостоятельно очищает временные файлы после выполнения.
Тесты покрывают три основных направления:
- **Чтение данных** — проверка работы всех реализаций `Reader`: валидные записи, конфликтующие серийные номера, ошибки валидации.
- **Запись данных** — проверка работы `Writer`: корректный расчёт показаний, обработка некорректных строк.
- **Сценарии с особыми счетчиками** — проверка логики перераспределения показаний в зависимости от адреса и коэффициента.
